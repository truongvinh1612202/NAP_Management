This project is a desktop application built with Electron, React, and TypeScript. It provides a user interface for managing and analyzing data.

Core features:
- Authentication
- Render large data in table views:
    - Implement lazy loading and pagination (High priority)
    - Support sorting and filtering (High priority)
    - Provide advanced filtering options (Medium priority)
    - Enable row grouping and aggregation (Medium priority)
    - Implement Excel export functionality (Low priority, Optional)
    - Add integrated charting capabilities (Low priority, Optional)

Notes:
- The current version of the project support view-only data, user can not modify data.
